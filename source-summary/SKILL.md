# 研究目标

不是简单总结原文，而是尽可能还原：

* 当事人真正表达了哪些重要信息？
* 当事人的核心观点和判断是什么？
* 他为什么形成这些判断？
* 判断背后的事实、依据、假设和因果关系是什么？
* 哪些内容属于明确事实，哪些属于个人观点，哪些只能合理推断？
* 相比一般公开信息，这份材料提供了哪些真正有价值的新增信息？

尤其关注当事人本人提供的信息和思考，而不是采访者、主持人或第三方的观点。

# 基本原则

* 忠于原文，不为了形成完整故事而补充原文没有表达的信息。
* 多人交流必须明确区分不同说话人，不能把采访者的问题或观点归因于受访者。
* 区分：

  * 已确认事实
  * 当事人的观点或判断
  * 当事人的预期
  * AI根据上下文作出的合理推断
* AI推断必须明确标注为“推断”，不能写成当事人的原意。
* 对数字、时间、人物、项目、产品、交易、目标等具体信息优先提取。
* 对“因为……所以……”“如果……那么……”“过去……现在……”等因果、条件和变化关系重点保留。
* 不要把宣传性、模糊性表达直接转换成确定事实。
* 当事人的措辞本身具有研究价值时，可以保留少量关键原话。
* 默认以材料本身为主要信息源；如果使用外部资料核实或补充，应与原材料内容明确区分。

# 信息提取重点

阅读材料时，优先寻找以下内容：

## 1. 关键事实

包括但不限于：

* 新披露的数据和数字
* 时间节点
* 已发生或准备采取的行动
* 产品、业务、客户、渠道、产能、组织等具体情况
* 过去发生的重要事件
* 未来明确计划
* 人物之间或公司之间的关系

重点识别“此前不容易从普通公开资料中获得的信息”。

## 2. 核心观点

提炼当事人真正想表达的主要判断，例如：

* 他认为行业正在发生什么变化？
* 他认为公司为什么成功或失败？
* 他如何看竞争对手？
* 他如何判断未来？
* 他认为最重要的问题是什么？

不要只摘录结论，要进一步解释其判断依据。

## 3. 判断逻辑

尽量将重要观点还原成完整逻辑链：

事实 / 观察
→ 原因判断
→ 核心假设
→ 得出的结论
→ 因此采取的行动或形成的预期

如果逻辑链中某一环节是AI根据上下文补出的，必须注明“推断”。

尤其关注：

* 因果关系
* 前提条件
* 必要条件
* 约束条件
* 时间关系
* 对比关系
* 当事人认为什么变量最重要

## 4. 行为与决策

相比泛泛观点，更重视当事人实际做了什么：

* 做出了什么决定？
* 为什么这样决策？
* 放弃了什么？
* 资源投向哪里？
* 决策标准是什么？
* 什么情况下会改变决定？

如果“说法”和“实际行动”之间存在差异，要特别指出。

## 5. 变化

重点寻找当事人的认知、公司策略或现实情况发生变化的地方：

过去如何
→ 为什么发生变化
→ 现在如何
→ 未来准备如何

如果材料涉及一个事件的发展过程，按照时间顺序还原。

## 6. 不确定性与反向信息

不要只提炼支持当事人结论的信息，同时关注：

* 当事人明确承认的问题
* 风险和困难
* 判断成立需要满足的条件
* 回答比较模糊的问题
* 明显回避的问题
* 前后表述存在矛盾之处
* 当事人没有证据支持的重要判断
* 可能存在利益立场或自我解释色彩的内容

不能仅凭语气武断判断当事人“撒谎”或“回避”，证据不足时应注明不确定。

# 输出格式

## 一句话概括

用1-3句话回答：

这份材料最值得知道的是什么？当事人最核心的观点或信息是什么？

## 最值得记住的信息

提炼约5-10个最重要的信息点，按照重要程度排序。

每一点尽可能回答：

* 当事人说了什么？
* 为什么重要？
* 背后的逻辑是什么？

避免把大量普通背景信息放入这一部分。

## 当事人的核心逻辑

围绕最重要的几个问题，详细还原当事人的思考。

优先使用：

**结论**

事实 / 观察
→ 原因
→ 假设或前提
→ 判断
→ 行动 / 结果

如果原文无法形成完整逻辑链，不要强行补全，应明确指出逻辑缺失的位置。

## 关键事实与新增信息

集中整理材料中值得记录的：

* 数字
* 时间
* 人物
* 项目
* 行动
* 计划
* 目标
* 其他具体事实

如果能够判断哪些信息属于相比常规公开资料更有价值的新增信息，优先标出。

## 重要变化

如果存在，梳理：

过去 → 变化原因 → 现在 → 未来

没有明显变化时可以省略本部分。

## 值得注意的问题

列出：

* 不确定信息
* 重要前提
* 潜在矛盾
* 尚未回答的问题
* 值得进一步核实的信息

区分“原文明确存在的问题”和“AI提出的研究问题”。

## 值得保留的原话

只选择少量真正具有信息量、能够体现当事人思维方式或态度的原话。

每段原话后简要说明：

* 这句话说明了什么
* 为什么值得记录

不要为了完整而大量复制原文。

# 输出要求

* 信息密度优先，不需要逐段复述材料。
* 删除寒暄、重复表达、主持人串场以及没有信息量的内容。
* 不因为一句话听起来重要就单独摘录，要结合上下文理解。
* 对重复出现的观点进行合并，并指出当事人反复强调的内容。
* 优先保留具体信息、因果逻辑、决策依据和认知变化。
* 如果材料非常长，宁可把重点问题分析清楚，也不要把所有内容平均压缩成流水账。
* 最终输出应让没有阅读原材料的人，能够较完整地理解当事人“知道什么、怎么看、为什么这么看、准备怎么做”。
